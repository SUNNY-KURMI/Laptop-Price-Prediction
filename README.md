# Laptop Price Tracker

A single Streamlit app: enter a laptop's specs, get an ML-predicted fair
price, and compare it against live market prices. No separate backend —
the ML model and all logic run inside the Streamlit app itself.

## Run locally

```bash
pip install -r requirements.txt
cd ml && python train.py && cd ..   # trains the model, only needed once
streamlit run app.py
```

Open http://localhost:8501.

## Optional: live prices and price history

The app works immediately with just the predictor. To enable the other
two tabs:

1. Copy `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml`.
2. Add your SerpAPI key (serpapi.com, free tier) for "Compare prices".
3. Add your Firebase service account fields for "Price history" (create
   a Firebase project, enable Firestore, Project Settings -> Service
   Accounts -> Generate new private key).

`.streamlit/secrets.toml` is gitignored — never commit it.

## Deploy

1. Push this repo to GitHub (the `.gitignore` already excludes secrets).
2. Go to share.streamlit.io, sign in with GitHub, "New app", pick this
   repo, set main file to `app.py`.
3. In the app's Settings -> Secrets, paste the same content you put in
   your local `secrets.toml`.
4. Deploy. One URL, one service, nothing else to configure.

## Project structure

```
app.py              the entire application (UI + prediction + price APIs)
ml/
  laptop_price.csv  training data (1,303 real laptop listings)
  train.py          trains and evaluates 3 models, saves the best one
model/
  laptop_model.pkl  trained pipeline (generated by train.py)
  metrics.json      evaluation metrics (generated by train.py)
```

## Retraining

```bash
cd ml
python train.py
```

Prints MAE, MSE, RMSE, R² and MAPE for Linear Regression, Random Forest
and Gradient Boosting, and saves the best one.
